# 🛒 Market Basket Analysis & Cross-Selling Recommendation System

A complete **Market Basket Analysis and Product Recommendation System** built using Python and Association Rule Mining.

This project analyzes grocery transaction data to discover relationships between products that are frequently purchased together. It implements both **Apriori** and **FP-Growth** algorithms to generate frequent itemsets and association rules.

The discovered relationships are then used to build a **Product Recommendation System** that can be applied to a practical **Cross-Selling** use case.

# 📌 Project Overview

**Market Basket Analysis (MBA)** is a data mining technique used to discover relationships between products based on customer transaction data.

This project uses a grocery transaction dataset to answer questions such as:

- Which products are frequently purchased together?
- Which products have strong associations?
- What products can be recommended when a customer selects a particular product?
- How can these recommendations be used for cross-selling?

The project implements two popular frequent itemset mining algorithms:

- **Apriori**
- **FP-Growth**

The frequent itemsets generated by these algorithms are used to create **Association Rules**.

The rules are evaluated using:

- **Support**
- **Confidence**
- **Lift**

The final association rules are used to create a **Top-N Product Recommendation System**.
